# 00. 새 세션 시작하기

## 먼저 — 반드시 "내 컴퓨터에서" 실행할 것

이전 세션은 **클라우드 샌드박스**에서 돌았다. 그 환경은 유성님 맥에 파일 통로만
연결돼 있고 **네트워크가 없어서** 아래를 실행하지 못했다:

- `pod install` / `./gradlew` / `yarn install` (레지스트리 접근 불가)
- `firebase deploy` (자격증명·네트워크 없음)
- `xcodebuild` (애초에 macOS가 아님)
- 파일 **삭제**조차 불가 → `.git/index.lock`이 두 번 남았던 원인

**Claude 데스크톱 앱에서 새 작업을 시작할 때, 우측 상단 "이 작업 실행" 선택기에서
「내 컴퓨터에서」를 고를 것.** (Settings → Cowork → "새 작업을 클라우드에서 실행" 토글로
기본값도 바꿀 수 있다. 이미 시작된 세션은 옮길 수 없으니 새 작업으로 시작해야 한다.)

그렇게 하면 셸이 맥에서 그대로 돌아 빌드·배포까지 Claude가 직접 실행할 수 있다.

## 연결할 폴더

## 바로 이어서 할 일

가장 앞에 있는 건 **iOS Xcode 실기기 빌드 검증**이다.
`pod install`은 통과했고 Xcode로 열어서 빌드만 남았다.

```bash
open ~/StudioProjects/routefinding/app/ios/RouteFinding.xcworkspace
```
⚠️ `.xcodeproj`가 아니라 **`.xcworkspace`**. Scheme의 Build Configuration을 `Release`로
바꿔야 Metro 없이 실기기에서 단독 실행된다.
