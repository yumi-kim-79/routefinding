4. `~/keys/upload_certificate.pem` 업로드 → 제출

> 영영 업데이트할 수 없었다.

⚠️ **`~/keys/routefinding-upload.jks`를 비밀번호와 함께 백업할 것.** 또 잃으면 같은 절차 반복이다.

### 2-2. 🚨 지문 등록 3건 — **승인과 무관하게 지금 할 수 있고, 안 하면 스토어에서만 깨진다**

Play 앱 서명은 우리가 올린 AAB를 **앱 서명 키로 다시 서명**해서 배포한다.
따라서 **사용자 기기의 SHA-1은 우리 업로드 키가 아니다**:

```
앱 서명 키 SHA-1 : 3C:79:9A:EC:35:87:C5:98:AC:04:67:DA:AE:17:8D:93:57:AB:6C:9D
앱 서명 키 SHA-256: B9:89:49:5B:E4:0E:AA:30:13:28:A7:E4:AD:BC:1A:BA:BA:F8:12:57:B9:97:F2:43:21:F3:ED:18:82:0A:90:D7
```

- [ ] **Google Maps API 키**
      Cloud Console → API 및 서비스 → 사용자 인증 정보 → Android 키
      → 앱 제한에 `com.yusung.routefinding` + 위 **SHA-1** 추가
      → 빠뜨리면 **스토어 버전에서 지도가 회색**으로만 나온다
- [ ] **Firebase 디지털 지문**
      Firebase 콘솔 → 프로젝트 설정 → 내 앱(Android) → 디지털 지문 추가
      → 위 **SHA-1 + SHA-256** 둘 다
      → 빠뜨리면 **App Check(Play Integrity) 토큰 실패 → Firestore·Storage 접근 차단**
- [ ] **`google-services.json` 다시 받아 교체** → `app/android/app/google-services.json`
      (지문 추가 후 반드시 새로 받을 것. 받으면 Claude에게 주면 교체·커밋한다)

> 이 셋은 **빌드로는 절대 안 잡히고 올린 뒤에야 드러난다.**
> → **내부 테스트 트랙에 먼저 올려** 지도·로그인을 확인하고 프로덕션으로 승격할 것.

| 필요 | 현재 |
|---|---|
| Gradle 8.11+ | 8.10.2 |

## 5. 알아두면 좋은 것 (오늘 겪은 함정)

- **`peerDependencies`는 호환을 보장하지 않는다.** 이번엔 패키지가 아니라 **그 패키지가
  끌어오는 구글 SDK**가 Kotlin 2.1을 요구해 빌드가 깨졌다 → RNGMA 14.7.2로 고정.
- **R8은 필드를 남겨도 그 필드의 타입 클래스는 지운다.** `includedescriptorclasses`가 없으면
  New Architecture 앱이 **시작 즉시 죽는다.**
- **`ndk { abiFilters }`를 buildType에 써도 소용없다.** AGP가 defaultConfig와 **합집합**으로
  합치기 때문. ABI는 `gradle.properties`의 `reactNativeArchitectures`에서 정한다.
- **Groovy `versionCode (X) as Integer`** 는 `versionCode(X)` 호출로 파싱된다 → `Integer.parseInt` 사용.
- 기기 설정에 뜨는 앱 용량은 APK보다 크다(설치 시 dex 최적화). APK 실측은 `ls -l`로 볼 것.
