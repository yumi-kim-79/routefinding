### 완성된 기능
| 기능 | 내용 |
|---|---|
| 개념도 | **검색해야 목록이 뜬다**(검색 전 Firestore 읽기 0). 30개씩 무한스크롤, lazy 이미지 |
| 개념도 사진 | 촬영/첨부 → **사진 위에 라인·텍스트 그리기** → 승인 요청 |
| 사진 승인 | 관리자가 **승인·추가 / 승인·교체 / 반려**. 승인 전엔 올린 본인만 조회(규칙이 보장) |
| 등반일지 | `users/{uid}/climbing_logs` 날짜별 1건. 스프레드시트 컬럼과 1:1 |
| 마이페이지 | 3탭(내 제보 관리 / 등반일지 / 마이프로필). **등급·포인트 전면 제거**, 프로필 사진 변경 |
| 루트제보 | 위경도에 **현재위치 / 지도에서 선택** 버튼. 어프로치 실시간 기록 제거, GPX 업로드 유지 |
| 지도 | 마커 숫자를 핀 머리로, 핀 끝이 실제 좌표에 오도록 앵커 실측 보정 |
| 아이콘 | 이모지 전부 제거 → 인라인 SVG(`components/common/AppIcon.vue`, 하단탭 `BottomNavBar.vue`) |

## 앱 (`~/StudioProjects/routefinding`, 브랜치 `v2`) — ⚠️ 절반 완성

안드로이드 실기기 실행 확인됨. iOS는 `pod install`까지 통과, Xcode 빌드 미검증.

| 탭 | 상태 |
|---|---|
| 지도 | ⛔ **플레이스홀더** (react-native-maps 미도입) |

| 루트제보 | ⛔ **플레이스홀더** (작성 화면 자체가 없음) |
| 마이페이지 | ✅ 제보관리 / 등반일지 / 마이프로필(사진 변경 포함) |

### 오늘 앱에서 한 일
- RNFB **24.0.0 → 25.1.0** 업그레이드 (iOS 빌드 복구 목적)
- `types/auth.ts`: `FirebaseAuthTypes.User` → `User` (모듈러 타입)
- `services/firebase.ts`: App Check를 `new ReactNativeFirebaseAppCheckProvider()` 모듈러 방식으로
- `ios/Podfile`: **`use_modular_headers!` 제거 → static framework 방식** (gRPC 문제의 진짜 원인)
- `react-native-image-picker` 도입 (프로필 사진 변경)
- `Info.plist`: 빈 문자열이던 위치 권한 문구 채움 + 사진 권한 추가
- 4탭 재구성, 마이페이지 3탭, 등급·포인트 제거, 등반일지 신설

`tsc --noEmit` 0 error / `eslint` 0 error.
