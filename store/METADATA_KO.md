# 스토어 등록 문구 (한국어)

> 2026-08-06 작성. **글자 수는 실제로 세어 넣었다** — 스토어가 초과분을 잘라내면
> 문장이 어색하게 끊긴다.
>
> ⚠️ 애플 검색은 **이름 + 부제 + 키워드**만 색인한다. **설명은 검색에 잡히지 않는다.**
>    (구글 플레이는 설명도 색인한다 — 그래서 아래 설명은 플레이 기준으로 썼고
>     애플에서는 '전환율'과 'AI 답변 인용'을 노린다)

---

## 1. 앱 이름 — 18/30자

```
루트파인딩: 암벽등반 루트 개념도
```

브랜드(루트파인딩)를 앞에, 검색어(암벽등반·루트·개념도)를 뒤에.
`개념도`는 이 바닥에서 실제로 쓰는 말이라 `토포`보다 검색량이 크다.

## 2. 부제 — 21/30자

```
인수봉·북한산 클라이밍 토포와 등반일지
```

**고유명사를 넣는 게 핵심이다.** "클라이밍 앱"으로 검색하는 사람보다
"인수봉"으로 검색하는 사람이 우리 사용자에 가깝다.
`토포`는 여기서 흡수한다(이름에 `개념도`가 있으니 둘 다 잡힌다).

## 3. 키워드 — 96/100자 (App Store 전용)

```
볼더링,리드,스포츠클라이밍,자연암벽,실내암장,등반,멀티피치,어프로치,난이도,등반기록,암장,산악,홀드,GPX,토포도,빌레이,선등,크럭스,피치,루트지도,climbing,topo
```

규칙:
- **쉼표 뒤에 공백을 넣지 않는다** (공백도 글자 수를 먹는다)
- **이름·부제에 이미 있는 말은 넣지 않는다** (애플이 셋을 합쳐 색인한다 — 중복은 낭비)
- 복수형·조사 변형은 넣지 않는다 (애플이 알아서 처리한다)

## 4. 프로모션 텍스트 — 70/170자 (App Store 전용)

**심사 없이 아무 때나 바꿀 수 있다.** 공지·업데이트 소식용으로 쓴다.

```
전국 5,400여 개 암벽 루트를 지도와 개념도로. 사진 위에 그려진 등반 라인을 보고,
직접 제보하고, 등반일지로 기록하세요.
```

## 5. 설명

> 앞 3줄이 '더보기' 전에 보이는 전부다. **거기서 승부가 난다.**
> AEO(AI 답변 엔진) 관점에서도 앞부분에 "무엇을 하는 앱인지"를 사실 문장으로
> 명확히 두는 편이 인용되기 쉽다.

```
루트파인딩은 국내 암벽 등반 루트를 지도와 개념도로 찾아보는 앱입니다.
전국 5,400여 개의 승인된 루트를 담고 있으며, 인수봉·북한산·무의도를 비롯한
자연암벽과 실내 암장의 루트를 등반지·구역·루트명으로 검색할 수 있습니다.

■ 사진 위에 그려진 등반 라인
개념도(토포)는 실제 바위 사진 위에 라인과 글자를 얹은 것입니다.
어디로 올라가는지, 확보물이 어디 있는지, 크럭스가 어디인지 사진 한 장으로 파악할 수 있습니다.
리드는 피치별로, 볼더링은 문제별로 정리돼 있습니다.

■ 지도에서 루트 위치 확인
루트가 지도 위에 표시됩니다. 가까운 지점은 하나로 묶어 보여주므로
바위 하나에 루트가 여러 개 있어도 화면이 복잡해지지 않습니다.
GPX 파일이 등록된 루트는 접근로를 지도에서 따라 볼 수 있습니다.

■ 직접 제보하고 함께 만듭니다
새 루트를 발견했다면 사진을 찍어 그 자리에서 라인을 그려 제보할 수 있습니다.
등반지·구역·좌표는 보고 있던 개념도에서 자동으로 채워집니다.
제보는 관리자 확인을 거쳐 모두에게 공개됩니다.

■ 등반일지
언제 어디서 무엇을 올랐는지, 함께한 사람과 장비, 소요 시간까지 남길 수 있습니다.
개념도에서 바로 일지를 쓸 수 있어 장소와 루트명을 다시 입력할 필요가 없습니다.

■ 즐겨찾기
가고 싶은 루트를 저장해 두고 마이페이지에서 한 번에 봅니다.

────────────────
· 무료로 사용할 수 있으며 하단에 배너 광고가 표시됩니다.
· 회원가입(이메일) 후 이용할 수 있습니다.
· 등반은 위험을 동반하는 활동입니다. 앱의 정보는 참고용이며,
  실제 등반 판단과 안전 확보는 등반자 본인의 책임입니다.
```

## 6. 카테고리 · 그 외

| 항목 | 값 |
|---|---|
| 기본 카테고리 | 스포츠 |
| 보조 카테고리 | 내비게이션 (또는 여행) |
| 가격 | 무료 |
| 연령 등급 | 사용자 생성 콘텐츠 있음 → 보통 4+ 또는 12+ |

## 7. 왜 이렇게 썼나 (다음에 고칠 때 참고)

- **고유명사 > 일반명사.** "클라이밍 앱"은 경쟁이 심하고 우리보다 큰 앱이 이긴다.
  "인수봉", "북한산"은 검색량은 적지만 **찾는 사람이 정확히 우리 사용자**다.
- **숫자를 넣었다.** "5,400여 개"는 AI 답변 엔진이 인용하기 좋은 형태다.
  "많은 루트"는 인용되지 않는다.
- **기능 나열이 아니라 상황으로 썼다.** "개념도 기능 지원"이 아니라
  "사진 한 장으로 파악할 수 있습니다".
- **안전 문구를 넣었다.** 등반 앱은 심사에서 안전 관련 지적을 받을 수 있고,
  넣어서 손해 볼 일이 없다.
- ⚠️ 애플은 **설명에 경쟁 앱 이름·가격·"최고" 같은 표현**을 넣으면 반려한다. 넣지 않았다.
